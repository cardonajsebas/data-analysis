# Data Analysis Portfolio

A collection of data analysis projects covering exploratory analysis, ETL pipeline design, and business case studies. Each project follows a structured analytical workflow from data ingestion to insight communication.

---

## Projects

### 1. Global Education & Economic Pipeline

An end-to-end ETL pipeline analyzing the relationship between national GDP and educational outcomes (PISA scores) across 200+ countries.

| | |
|---|---|
| **Tech** | Python, SQL (SQLite), Tableau |
| **Dataset** | World Bank open data |
| **Scope** | ETL pipeline, relational database, SQL aggregation views, Tableau dashboard |

Built a pipeline that cleans and loads raw World Bank data into a SQLite database, then uses SQL views to calculate aggregations across continents and sub-regions. Analysis identified a diminishing return pattern between GDP and educational outcomes, suggesting that beyond a certain wealth threshold, spending strategy matters more than total budget.

[View project](https://github.com/cardonajsebas/data-analysis/tree/main/world_education)

---

### 2. E-commerce Customer Behavior - Exploratory Data Analysis

Exploratory data analysis on transactional e-commerce data to identify seasonal sales trends and customer segmentation patterns.

| | |
|---|---|
| **Tech** | Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebooks |
| **Scope** | EDA, trend analysis, customer segmentation, visualization |

Analyzed sales patterns across product categories and time periods. Findings informed inventory adjustment recommendations based on categorical performance and seasonal demand.

[View project](https://github.com/cardonajsebas/data-analysis/tree/main/ecommerce_eda)

---

### 3. Google Data Analytics Case Study - Bellabeat

A structured business case study following the Ask, Prepare, Process, Analyze, Share, and Act framework to analyze fitness tracker usage data and recommend a marketing strategy.

| | |
|---|---|
| **Tech** | R, Spreadsheet analysis |
| **Dataset** | Fitbit fitness tracker data (Kaggle) |
| **Scope** | Data cleaning, behavioral pattern analysis, business recommendations |

Processed millions of rows of raw activity data to identify user behavior patterns. Delivered data-driven recommendations for a marketing campaign targeting increased device engagement.

[View project](https://github.com/cardonajsebas/data-analysis/tree/main/google_da_case_study)
